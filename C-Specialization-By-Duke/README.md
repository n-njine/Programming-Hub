# C Programming — Duke University

## About This Repository

This repository documents my journey through the **C Programming Specialization offered by Duke University**.

What started as an effort to understand the fundamentals of programming gradually evolved into something much more substantial: developing the ability to reason about problems, translate ideas into algorithms, manage memory, understand pointers, and write increasingly complex programs in C.

Over approximately **five months of consistent work**, I worked through the course material, tackled programming exercises, debugged challenging problems, and strengthened my understanding of how programs work beyond simply getting them to compile.

This repository serves as a practical record of that journey.

It contains my implementations, exercises, experiments, and other learning materials developed throughout the course.

## What You'll Find Here

The repository brings together practical work covering different aspects of programming in C, including:

### 1. Programming Fundamentals
- Variables, data types, and operators.
- Expressions and control flow.
- Conditional statements and loops.
- Functions and modular programming.
- Problem-solving and algorithm development.

### 2. Working with Data
- Arrays and multidimensional arrays.
- Character arrays and strings.
- Structures and user-defined data types.
- Processing and manipulating data.

### 3. Pointers and Memory Management
- Understanding pointers and memory addresses.
- Pointer arithmetic.
- Passing pointers to functions.
- Dynamic memory allocation.
- `malloc()`, `calloc()`, `realloc()`, and `free()`.
- Memory management and common memory-related errors.

### 4. Working with the System
- Command-line arguments.
- File handling and input/output.
- Reading from and writing to files.
- Understanding how C programs interact with their environment.

### 5. Testing, Debugging and Problem Solving
- Writing and testing programs against different inputs.
- Identifying logical and runtime errors.
- Debugging programs systematically.
- Investigating memory-related problems.
- Improving program correctness and reliability.

*The repository structure and individual exercises reflect the actual progression of my coursework.*

## My Learning Approach

I believe learning programming is about much more than memorizing syntax or reproducing code.

Throughout this journey, I have tried to focus on understanding the underlying concepts, implementing solutions independently, testing different approaches, and learning from mistakes.

Some of the most valuable lessons came from programs that didn't work as expected.

Understanding why a program fails, tracing its execution, investigating memory behaviour, and correcting mistakes are all part of becoming a better programmer.

The goal has never been simply to finish exercises, but to develop the ability to approach unfamiliar problems and solve them independently.
